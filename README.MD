# Customer Shopping Preference Prediction\
\
## Project Overview\
This project analyzes customer behavior to predict their preferred shopping channel:\
Online, Store, or Hybrid.\
\
The dataset contains demographic information, shopping habits, and digital usage patterns.\
\
## Dataset\
Records: 11,789  \
Features: 26\
\
Data includes:\
- Age\
- Monthly income\
- Internet usage\
- Delivery preferences\
- City tier\
- Shopping habits\
\
## Objective\
Build a machine learning model that predicts a customer's shopping preference.\
\
## Technologies Used\
Python\
Pandas\
NumPy\
Scikit-learn\
Matplotlib\
Seaborn\
\
## Machine Learning Model\
Random Forest Classifier was used to predict the target variable.\
\
## Steps\
1. Load dataset\
2. Data exploration\
3. Data preprocessing\
4. Train-test split\
5. Train machine learning model\
6. Evaluate model accuracy\
\
## Result\
The model predicts customer shopping preferences with good accuracy and can help businesses understand customer behavior.}
